# FITBITE — cyberpunk 3D-wandeling

Bron van `../fitbite-cyberpunk-3d.html`: één zelfstandig HTML-bestand (three.js, code, lettertypen en
texturen ingesloten) dat je rechtstreeks in de browser opent.

Opnieuw bouwen:

    npm install
    node build.mjs

- `src/exterior.js` gevel en straat · `src/fitbite.js` podium, toonbank, keuken, opslag · `src/hall.js` hal
- `src/main.js` besturing, rondleiding, kwaliteit · `src/reflect.js` natte-vloerspiegeling · `src/rain.js` regen
- `assets/` menuschermen en saladebar, rechtgetrokken uit de eigen foto's; lettertypen (OFL)

Afmetingen zijn geschat op basis van foto's en video, niet opgemeten.
